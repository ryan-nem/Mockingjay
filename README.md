# Mockingjay

*May the odds…*

The league's NFL betting challenge as a Home Screen app for iPhone and Android.

- The app files here (HTML, CSS, JavaScript, icons) are public by design. They hold no secrets.
- All data and every rule (who you are, wager caps, kickoff locks, bankroll limits, grading) live in the league's Google Apps Script, which checks each player's private link on every request.
- `config.js` holds the Apps Script web app URL.

Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
